# Скрипт обзвона / переписки с лофтами

Для агента, который собирает цены и даты. Результат — одна строка на лофт в
`data/calls/YYYY-MM-DD.csv` (колонки ниже). Канал: Telegram/WhatsApp лофта, если
есть; иначе звонок. Пишем от первого лица, коротко, без «мы агрегатор».

## Приоритет

1. ЦАО и станции: Курская, Бауманская, Таганская, Павелецкая, Тульская, Савёловская,
   Дмитровская, Белорусская.
2. Вместимость 20–80 человек.
3. Потом остальные.

## Сообщение-открывашка (мессенджер)

> Здравствуйте! Подбираю лофт на корпоратив в декабре, 30 человек, суббота с 18 до 23.
> Подскажите, пожалуйста:
> 1) какие даты с 12 по 27 декабря ещё свободны;
> 2) сколько выйдет итого за вечер — с минимальными часами, уборкой и залогом;
> 3) можно ли свой алкоголь и своя еда/кейтеринг, есть ли пробковый сбор;
> 4) до скольки можно шуметь.
> Спасибо!

Если отвечают — дожать недостающее из таблицы. Если спрашивают «кто вы» — честно:
«делаю каталог лофтов loftmap.ru, разместил вас бесплатно, хочу показать актуальную
цену и даты, а не “от 400 ₽/час”». Спросить, можно ли присылать им заявки напрямую. В конце — отправить ссылку на правку
карточки (`loftmap.ru/edit/?t=…`, выдаёт владелец) со словами: «тут можете сами
менять цены и свободные даты, без регистрации».

## Что записать (колонки CSV)

| колонка | что спрашиваем | формат |
|---|---|---|
| id | slug из `lofts.csv` или новый | `kutuzov-loft` |
| name | | |
| contact_channel | как связались | `tg` / `wa` / `phone` / `form` |
| contact_person | имя менеджера | |
| cap_seated | «сколько человек сидя за столами» | число |
| cap_standing | «сколько стоя/фуршет» | число |
| price_evening_30 | итого за вечер, 30 чел, сб 18–23, декабрь, со всеми сборами | число ₽ |
| price_evening_50 | то же на 50 чел (если отличается или другой зал) | число ₽ |
| price_hour_weekday / price_hour_weekend | ставка в час будни / выходные | число |
| min_hours | минимум часов | число |
| deposit | залог | число ₽ |
| cleaning_fee | уборка | число ₽, 0 если входит |
| corkage | свой алкоголь | `free` / `fee:3000` / `no` |
| own_catering | своя еда/кейтеринг | `yes` / `no` / `only_partner` |
| noise_after_23 | шуметь после 23 | `ok` / `quiet` / `no` |
| close_time | до скольки можно находиться | `02:00` / `24h` |
| new_year_surcharge | наценка на даты 20–31.12 | «+30%» или «нет» |
| free_dates_dec | свободные даты 10–30 декабря | `2026-12-12;2026-12-19;2026-12-26` |
| booked_dates_dec | занятые (если сказали) | тот же формат |
| kitchen / sound / projector / parking | есть ли | `yes`/`no` |
| photos_ok | разрешили использовать их фото | `yes`/`no`, ссылка если прислали |
| leads_ok | согласны получать заявки от нас | `yes`/`no` |
| edit_link_sent | отправили ссылку на правку | `yes`/`no` |
| checked_at | дата контакта | `2026-10-15` |
| notes | всё остальное словами | |

## Правила

- Записываем только то, что сказали; не додумываем. Пусто лучше, чем догадка.
- Если цена «зависит» — просим посчитать на 30 человек в субботу 19 декабря 18–23.
- Не ответили за 2 дня — второй пинг. Не ответили на второй — `notes: no_answer_2`,
  идём дальше.
- Нельзя: обещать брони, обсуждать комиссии, обещать «бесплатную рекламу навсегда».
