# Скрипт переписки с лофтами (v2, 12.10.2026)

Для агента, который проверяет цены лофтов. Канал — только мессенджеры: Telegram, если
есть; иначе WhatsApp по номеру из карточки. Не звоним. Пишем от первого лица, коротко,
без «мы агрегатор».

Результат — одна строка на лофт в листе «Проверки» Google-таблицы «LoftMap — проверки»
(колонки ниже). Строку заводим, как только отправили первое сообщение (`status: sent`), и
дальше обновляем её же, новую не добавляем. Статус сам подтягивается в лист «Очередь».
Claude раз в день забирает таблицу в `data/calls/`.

## Цель

30–45 проверенных лофтов в неделю. Проверенный = есть ответы на все 4 вопроса.
Чтобы получить одну проверку, нужно начать 4–5 диалогов: открывайте ~40 новых диалогов
в день, в те же дни дожимайте недостающее.

## Приоритет

1. Станции: Курская, Бауманская, Таганская, Павелецкая, Тульская, Савёловская,
   Дмитровская, Белорусская, затем остальные в ЦАО.
2. Вместимость 10–40 человек.
3. Потом остальные.

Список — лист «Очередь» в той же таблице: 809 площадок, уже по приоритету, залы с одним
телефоном объединены (колонка «Залов»). Идём сверху вниз, пропуская строки со статусом.

## Сообщение-открывашка

> Здравствуйте! Ищу лофт на день рождения, 20 человек, суббота с 18 до 23.
> Подскажите, пожалуйста:
> 1) сколько выйдет итого за вечер — с минимальными часами, уборкой и прочими сборами;
> 2) можно ли свой алкоголь, есть ли пробковый сбор;
> 3) можно ли свою еду или кейтеринг;
> 4) до скольки можно шуметь.
> Спасибо!

Если отвечают частично — дожать недостающее. Если цена «зависит» — попросить посчитать
на 20 человек в субботу 18–23 в ближайший месяц.

Если спрашивают «кто вы» или после ответа — честно:
> «Делаю каталог лофтов loftmap.ru, вы там уже есть бесплатно. Хочу показать вашу
> реальную цену за вечер, а не “от N ₽/час”. Можно присылать вам заявки от гостей
> напрямую? Это бесплатно.»

Ответ на последний вопрос — колонка `leads_ok`.

## Колонки таблицы

| колонка | что записать | формат |
|---|---|---|
| id | из листа «Очередь» | `kutuzov-loft` |
| name | подставляется сам по id | |
| contact_channel | где ответили | `tg` / `wa` |
| contact_person | имя менеджера | |
| price_evening_20 | итого за вечер, 20 чел, сб 18–23, со всеми сборами | число ₽ |
| price_hour | ставка в час, если назвали | число ₽ |
| min_hours | минимум часов, если назвали | число |
| deposit | залог, если назвали | число ₽ |
| corkage | свой алкоголь | `free` / `fee:3000` / `no` |
| own_catering | своя еда | `yes` / `no` / `only_partner` |
| noise_until | до скольки можно шуметь | `23:00` / `02:00` / `24h` |
| cap_seated | сидя, если назвали | число |
| leads_ok | согласны получать заявки | `yes` / `no` |
| checked_at | дата ответа | `2026-10-15` |
| status | итог диалога | `sent` / `verified` / `partial` / `no_answer_2` / `closed` |
| notes | всё остальное словами | |

## Правила

- Записываем только то, что сказали. Пусто лучше, чем догадка.
- Не ответили за 2 дня — второй пинг. Не ответили на второй — `no_answer_2`, идём дальше.
- Лофт закрыт или номер не тот — `closed`.
- Свободные даты **не спрашиваем**.
- Нельзя: обещать брони, обсуждать комиссии, обещать «рекламу навсегда».
- Ссылки на правку карточки (`loftmap.ru/edit/?t=…`) пока **не отправляем**. Владелец
  скажет, когда они заработают (ориентир — конец октября).
