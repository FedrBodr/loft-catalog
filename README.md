# Каталог лофтов

Каталог всех лофтов Москвы без комиссии. Сделан для людей, которые ищут площадку
под свою задачу: день рождения, корпоратив, съёмка.

Статус: **идея / проверка гипотезы**. Кода пока нет.

- [docs/idea.md](docs/idea.md) — идея, рынок, чем мы лучше, на чём зарабатываем
- [docs/plan.md](docs/plan.md) — короткий план проверки

Связь с «Пространством»: каталог — витрина и источник заявок, а продаём 3D-карточки
и навигацию (репозиторий FedrBodr/prostranstvo).
